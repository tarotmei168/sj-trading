?? 潛力股候選 — 當前篩選邏輯完整說明

一句話總結：目前是按「投信連續買超天數 ≥ 3 天」+「累計買超金額 ≥ 50 萬」從全市場篩出，
再依累計買超金額由大到小排序，取前 40 名。沒考慮外資動向、也沒看股價位階。

一、資料來源

TWSE T86 全市場三大法人買賣超日報（網址：fund/T86?date=YYYYMMDD）
  • 抓最近 5 個交易日（含今天盤後資料）
  • 每檔股票的：投信買賣超、外資買賣超
  • 計算是 逐日累加：連買幾天、累計買了多少錢

二、篩選條件（daily_market_update.py）

條件說明
連買 ≥ 3 天投信連續買超天數（>=3）
累計買超 ≥ 50 萬最近 N 天投信累計買超總金額
排序按 total_trust 由大到小
取前 40 名寫入 trust_scan_latest.json → trust_top40[]

三、早報顯示邏輯（daily_web_report.py gen_html）

  1. 從 trust_scan_latest.json.trust_top40 讀取
  2. 再次篩選（退保險）連買 ≥ 3 天 + 累計 ≥ 50 萬
  3. 分兩組：持股（CORE_19）放前面，非持股放後面
  4. 各取前 10 名，最多 20 檔
  5. 沒有再重新排序——保留 T86 原始的累計買超金額降序

四、當前邏輯的盲點（為什麼會出現土洋對作）

問題原因
土洋對作股也被列入只看投信買超金額，不看外資是否出貨
股價在高檔也被列入沒用股價位階（30日高/低、RSI）過濾
連買天數少但金額大3 天也算，可能是短線拉抬而非建倉
沒考慮股本大小同樣買1億，小股本 vs 大股本意義不同（滲透率）

例：南亞（1303）投信連5天買1.4億，但外資同期賣超1.55億 → 被標記 🔴對作。這確實不是理想潛力股，因為外資在出貨。

五、我的建議：應該怎麼改進

改善方向建議做法
1. 過濾土洋衝突排除外資同期賣超 > 投信買超 50% 的（嚴重對作）
2. 加入位階評估股價在近 30 日低點 15% 內才視為潛力（低檔建倉）
3. 加入滲透率權重投信持股佔股本比例（P_cum），比純金額更有意義
4. 連買天數加權連買 5 天以上權重高於 3 天的（真正連續建倉）
5. 外資共買加分投信+外資同買的 🟢共愛 排在前面

最終建議的排序公式：
score = total_trust × (1 + days/10) × (1 + 位階加分) × (外資方向係數)
其中外資方向係數：同買=1.5，小對作(外資賣超<投信買超的50%)=1.0，嚴重對作=排除

六、永豐金 API 是否有熱門排行？

永豐金 Shioaji API 沒有直接提供「熱門量排行榜」功能。

Shioaji 能做的事：

  • 即時報價（tick/kbar）→ 只給價量
  • 三大法人買賣超 → 沒有，這要從 TWSE T86 抓
  • 個股新聞/財報 → 沒有
  • 沒有類似「全市場排行」、「熱門股」、「法人買超排行榜」的直接 API

目前全市場 T86 資料是從 TWSE 官方網站直接抓的（twse.com.tw/fund/T86），不需要 Shioaji。
