## 四、同步規則（最重要）

**每次修改關鍵字，必須：**

1. ✅ 更新 `NEWS_KEYWORD_FRAMEWORK.md`（本架構表）
2. ✅ 更新 `morning_news.py` 的 `KEYWORD_RULES` + `CHINA_FILTER`
3. ✅ 更新 `news_filter.py` 的 `IMPORTANT_KW`
4. ✅ 產一次測試確認關鍵字生效
5. ✅ git commit + push

**違反後果：** 關鍵字不同步 → 新聞分類錯亂 → 晨報品質下降 → 主人不爽
