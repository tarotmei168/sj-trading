| 事件 | 觸發條件 | 最多次數 | 發送時間 |

## 三、數據源架構（雙核心）

### 🎯 核心1：FinMind（盤後大數據，免費）

| API | 用途 | 更新頻率 |
|-----|------|---------|
| `taiwan_stock_info` | 全市場4,276檔基本資料 | 每月 |
| `TaiwanStockInstitutionalInvestorsBuySell` | 投信/外資買賣超 | 每日16:30 |
| `TaiwanStockMonthRevenue` | 月營收年增率 | 每月10號 |
| `TAIEX` | 大盤加權指數日K | 每日 |
| `TaiwanStockNews` | 產業新聞過濾 | 每日 |

**離線備援：** `database/{代號}_3y.csv` 本機日K（KD/RSI/支撐完全離線計算）

### 🎯 核心2：永豐金 Shioaji（即時報價 / 模擬模式）

| 功能 | 方法 | 說明 |
|------|------|------|
| 即時快照 | `api.snapshots()` | 取得現價/漲跌/最高最低/成交量 |
| 開盤基調 | `check_market_tone()` | 用台積電即時漲跌判斷多空 |
| 庫存對帳 | `api.list_positions()` | 需CA憑證，下單用 |
| 盤中監控 | 15分K/kbar | 待整合至 day_monitor_loop.py |

**⚠️ API Key 模擬模式：** 當 `SHIOAJI_API_KEY` 未設定或 Shioaji 套件未安裝時，自動啟用**模擬模式**——使用 FinMind 本機日K + 昨日收盤價作為近似值，不影響晨報產出。

## 四、晨報產出規則（daily_web_report.py）

### 📐 版型規範

| 項目 | 要求 |
|------|------|
| 字體 | **18px** 全頁統一（body 18px, table 18px, th 18px, td 18px） |
| 色系 | 深色模式（背景 #121212, 卡片 #1e1e1e, 金字 #ffbe76） |
| 指數 | **只留費城半導體 SOX**（不要道瓊/標普/那指） |
| 響應式 | 最大寬度 mobile-first |

### 📊 必備區塊（由上到下）

1. **🇺🇸 費半指數** — 最新收盤 + 漲跌幅 + 開盤基調
2. **🔒 第1層核心持股** — KD/RSI/支撐/漲跌/股本滲透率
3. **🎯 第2層潛力股** — 同核心表
4. **📅 未來14天事件** — 除息/法說/結算/季底
5. **🔗 台美產業聯動** — 美股波動>2%警報
6. **🏦 投信秘密建倉** — P_day滲透率 + P_cum累計控盤率 + 營收年增
7. **🗣️ 川普投顧** — 政治與關稅言論

### 🔢 股本滲透率公式（calc_trust_rate.py）

```
P_day = (V_day / price) / (S_total × 1000) × 100%
P_cum = sum(V_i) / (S_total × 1000) × 100%

V_day = 投信當日買超金額(元)
price = 昨日收盤價
S_total = 總發行張數（資本額/10）
```

## 七、錯誤處理原則

1. **FinMind API 失效** → 改用本機 local CSV（完全離線，不影響KD/RSI計算）
2. **Shioaji 無 API Key** → 啟動模擬模式，用 `calc_tech.py` 本機資料替代
3. **Git Push 失敗** → 只存檔，不中斷流程，下次重試
4. **JSON 編碼錯誤** → 統一 UTF-8, `ensure_ascii=False`
5. **任何例外** → `try/except` 捕獲後印出錯誤，不讓整個流程崩潰
