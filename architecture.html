📡 永豐金 Shioaji API — 即時狙擊槍

用途 1：08:30 晨報即時報價校正
api.snapshots → 核心持股現價、漲跌幅、最高/最低/成交量

用途 2：開盤基調判斷
即時台積電漲跌 → 強多/偏多/中性/偏空/強空

用途 3：盤中 15分K KD 金叉/死叉監控
(待 day_monitor_loop.py 整合)

用途 4：庫存持股對帳
api.list_positions → 真實庫存成本 vs 市價（需 CA 憑證）
